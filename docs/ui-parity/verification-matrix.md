## Commands currently enforced

```bash
pnpm ui:test
pnpm ui:check
pnpm ui:build
pnpm ui:visual
```

For an intentional Chromium baseline refresh, run `pnpm ui:visual:update`.
That command regenerates every fixed frame from the current worktree rather
than borrowing a developer server; review its PNG diff before committing.

## Commands required before Phase 1 sign-off

```text
PySide6 fixture capture (5 themes × target viewports × named states)
React Chromium screenshot capture using identical fixtures
Tauri/macOS screenshot capture using identical fixtures (`capture_tauri_macos.py`)
Pixel-diff report with approved masks only for dynamic values
Existing Python desktop test suite
```

The PySide6 capture waits through its density debounce before rendering a
golden. Do not use a transition frame as visual-source evidence.

The Chromium snapshots are regression baselines for the React implementation;
they deliberately do **not** constitute a claim of visual equivalence to the
PySide6 source. Cross-app acceptance remains blocked on equivalent source
fixtures and Tauri/macOS captures.
